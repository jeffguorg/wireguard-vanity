# 4.8 x25519.rs：clamp 与梯子主体

这节写 `src/x25519.rs`：clamp、cswap、Montgomery 梯子。原理都在 3.2/3.5 节，这里把代码完整敲出来。

## 文件头、cswap、clamp

整个文件内容如下（测试模块下节再加）。第一部分：

```rust
//! X25519（RFC 7748）： Montgomery 梯子 + 域求逆，只支持基点（u=9）。
//!
//! WireGuard 只需要 `X25519(私钥, 基点)`，所以不需要处理任意 u 坐标。

use crate::fe::{self, Fe};

/// 常数时间条件交换：swap=1 时交换 a、b，swap=0 时不变。
/// 用掩码而非分支实现（GPU 上也便宜）。
fn cswap(swap: u64, a: &mut Fe, b: &mut Fe) {
    let mask = 0u64.wrapping_sub(swap);
    for i in 0..10 {
        let t = mask & (a.0[i] ^ b.0[i]);
        a.0[i] ^= t;
        b.0[i] ^= t;
    }
}

/// 对 32 字节私钥做 RFC 7748 规定的 clamp。
pub fn clamp(k: &mut [u8; 32]) {
    k[0] &= 248;
    k[31] &= 127;
    k[31] |= 64;
}
```

- `cswap`：3.5 节的掩码交换原样落地。`0u64.wrapping_sub(swap)`：swap=1 时得到 `0−1` 回绕成全 1 的 mask；
- `clamp`：清低 3 位（`&= 248`，248 = 11111000₂）、清最高位（`&= 127`）、置位次高位（`|= 64`）。

> 💡 补给：`&mut Fe` 是可变引用——函数拿到的是「可以修改的借用」，调用处的值会被原地改掉，不用返回。`wrapping_sub` 显式告诉编译器「溢出回绕是我要的」，不要报错。

## 梯子主体

接着写：

```rust
/// X25519(scalar, u)，通用形式。
pub fn x25519_with_u(scalar: &[u8; 32], u: &[u8; 32]) -> [u8; 32] {
    x25519_impl(scalar, &fe::from_bytes(u))
}

/// X25519(scalar, 基点 9)，返回公钥的 32 字节小端序。
pub fn x25519_base(scalar: &[u8; 32]) -> [u8; 32] {
    // 基点 u 坐标 = 9
    x25519_impl(scalar, &Fe([9, 0, 0, 0, 0, 0, 0, 0, 0, 0]))
}

fn x25519_impl(scalar: &[u8; 32], x1: &Fe) -> [u8; 32] {
    let mut s = *scalar;
    clamp(&mut s);

    let x1 = *x1;
    let mut x2 = Fe::ONE;
    let mut z2 = Fe::ZERO;
    let mut x3 = x1;
    let mut z3 = Fe::ONE;

    let mut swap: u64 = 0;
    // 从高到低扫描 scalar 的 254..=0 位
    for t in (0..255).rev() {
        let bit = ((s[t / 8] >> (t & 7)) & 1) as u64;
        swap ^= bit;
        cswap(swap, &mut x2, &mut x3);
        cswap(swap, &mut z2, &mut z3);
        swap = bit;

        let a = fe::add(&x2, &z2);
        let aa = fe::sq(&a);
        let b = fe::sub(&x2, &z2);
        let bb = fe::sq(&b);
        let e = fe::sub(&aa, &bb);
        let c = fe::add(&x3, &z3);
        let d = fe::sub(&x3, &z3);
        let da = fe::mul(&d, &a);
        let cb = fe::mul(&c, &b);
        let da_plus_cb = fe::add(&da, &cb);
        let da_minus_cb = fe::sub(&da, &cb);

        x3 = fe::sq(&da_plus_cb);
        z3 = fe::mul(&x1, &fe::sq(&da_minus_cb));
        x2 = fe::mul(&aa, &bb);
        // z2 = E * (AA + a24 * E)，mul121665 的结果 limb 较大，先归约再参与运算
        z2 = fe::mul(&e, &fe::add(&aa, &fe::carry(&fe::mul121665(&e))));
    }
    cswap(swap, &mut x2, &mut x3);
    cswap(swap, &mut z2, &mut z3);

    // u = x2 / z2 = x2 * z2^(p-2)
    fe::to_bytes(&fe::mul(&x2, &fe::invert(&z2)))
}
```

对照 3.5 节的舞步逐行核：寄存器初始化（x2=1, z2=0, x3=x1, z3=1）→ 255 步循环 → 末尾补一次 cswap → `x2 · z2⁻¹` 输出。

两个容易漏的细节：

- `swap ^= bit; ...; swap = bit;`：交换条件是「当前位与上一位不同」，循环后 swap 持当前位留给下一轮；
- `fe::carry(&fe::mul121665(&e))`：兑现 4.5 节的约定——mul121665 不归约，这里先 carry 再参与加法，防止 limb 超标。

> 💡 补给：`s[t / 8] >> (t & 7)` 取标量第 t 位：第 t 位在第 `t/8` 个字节的第 `t%8` 位（`t & 7` 就是 t % 8）。`(0..255).rev()` 让循环从 254 倒着数到 0。
