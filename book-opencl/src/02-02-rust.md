# 2.2 安装 Rust 与 cargo 上手

这节在 GPU 主机上装好 Rust 工具链，并用一个迷你项目练会四个最常用命令。

## 安装 Rust

用官方推荐的 rustup 安装：

```console
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

一路回车选默认配置即可。装完后让当前 shell 认识 `cargo`：

```console
$ source ~/.cargo/env
$ cargo --version
cargo 1.xx.x ...
```

> 💡 补给：rustup 是 Rust 的工具链管理器，会帮你装好编译器 `rustc` 和包管理器 `cargo`，以后还能用 `rustup update` 一键升级。Arch 上也可以 `sudo pacman -S rust`，但 rustup 更方便跟进新版本，本书用它。

## cargo 四个命令

练手项目：

```console
$ cargo new hello
$ cd hello
```

`cargo new hello` 会生成一个目录：`Cargo.toml` 是项目清单（名字、依赖），`src/main.rs` 是代码入口。

```console
$ cargo build      # 编译，产物在 target/debug/hello
$ cargo run        # 编译 + 运行，输出 Hello, world!
$ cargo test       # 编译 + 运行测试
$ cargo run --release   # 以优化模式编译运行（慢编译、快运行）
```

记住这四个就够用完整本书：

| 命令 | 干什么 | 什么时候用 |
|---|---|---|
| `cargo build` | 只编译 | 检查代码有没有语法错误 |
| `cargo run` | 编译并运行 | 日常调试 |
| `cargo test` | 编译并跑测试 | 第 4 章验证正确性 |
| `cargo run --release` | 优化模式运行 | 第 7、8 章跑性能 |

> 💡 补给：默认 `cargo build` 是 debug 模式：编译快、运行慢（可能慢 10 倍以上）。`--release` 会打开全部优化。跑密码学这种计算密集任务一定要加 `--release`，否则你会以为 GPU 很慢——其实是 CPU 宿主代码没优化。

## 常见问题

- **编译慢**：第一次编译要下载并编译所有依赖库，属正常现象；
- **网络不通**：crates.io 被墙的话，搜「crates.io 镜像」配置国内源（如 rsproxy）。
