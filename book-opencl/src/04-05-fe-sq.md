# 4.5 fe.rs：sq

这节写平方 `sq`。平方是「自己乘自己」，比 mul 省约一半乘法——利用对称性：每一对交叉项只算一次再翻倍。

## 对称翻倍

f·f 的竖式里，`f1*f2` 和 `f2*f1` 是同一项，出现两次，所以写成 `2*f1*f2` 只乘一次。代码里 `f0_2 = 2*f0` 这类预翻倍就是在兑现这个对称性。

还有一个细节：h4 里的项 `f1_2 * f3_2`，系数是 4。为什么？f1、f3 都是奇 limb——奇×奇本来就要 ×2（权重原因，见 4.4），而对称交叉项又要 ×2，2×2 = 4，所以两个因子各翻倍一次。同理 `f5 * f5_38`：38 = 2×19，对角折叠项，奇 limb 的 2 乘进 19 里。

## 代码

接在 `mul` 后面：

```rust
/// 平方。利用对称性：每一对 (i<j) 只算一次再乘 2，对角项单独算。
/// 系数规则与 mul 相同（odd limb 折叠项 38，even limb 折叠项 19）。
pub fn sq(f: &Fe) -> Fe {
    let [f0, f1, f2, f3, f4, f5, f6, f7, f8, f9] = f.0;

    let f0_2 = 2 * f0;
    let f1_2 = 2 * f1;
    let f2_2 = 2 * f2;
    let f3_2 = 2 * f3;
    let f4_2 = 2 * f4;
    let f5_2 = 2 * f5;
    let f6_2 = 2 * f6;
    let f7_2 = 2 * f7;

    let f5_38 = 38 * f5;
    let f6_19 = 19 * f6;
    let f7_38 = 38 * f7;
    let f8_19 = 19 * f8;
    let f9_38 = 38 * f9;

    let h0 = f0 * f0 + f1_2 * f9_38 + f2_2 * f8_19 + f3_2 * f7_38 + f4_2 * f6_19 + f5 * f5_38;
    let h1 = f0_2 * f1 + f2 * f9_38 + f3_2 * f8_19 + f4 * f7_38 + f5_2 * f6_19;
    let h2 = f0_2 * f2 + f1_2 * f1 + f3_2 * f9_38 + f4_2 * f8_19 + f5_2 * f7_38 + f6 * f6_19;
    let h3 = f0_2 * f3 + f1_2 * f2 + f4 * f9_38 + f5_2 * f8_19 + f6 * f7_38;
    let h4 = f0_2 * f4 + f1_2 * f3_2 + f2 * f2 + f5_2 * f9_38 + f6_2 * f8_19 + f7 * f7_38;
    let h5 = f0_2 * f5 + f1_2 * f4 + f2_2 * f3 + f6 * f9_38 + f7_2 * f8_19;
    let h6 = f0_2 * f6 + f1_2 * f5_2 + f2_2 * f4 + f3_2 * f3 + f7_2 * f9_38 + f8 * f8_19;
    let h7 = f0_2 * f7 + f1_2 * f6 + f2_2 * f5 + f3_2 * f4 + f8 * f9_38;
    let h8 = f0_2 * f8 + f1_2 * f7_2 + f2_2 * f6 + f3_2 * f5_2 + f4 * f4 + f9 * f9_38;
    let h9 = f0_2 * f9 + f1_2 * f8 + f2_2 * f7 + f3_2 * f6 + f4_2 * f5;

    carry(&Fe([h0, h1, h2, h3, h4, h5, h6, h7, h8, h9]))
}
```

## 为什么值得单独写

X25519 的 255 步里每步 2 次平方，求逆更是 254 次平方连发——平方的总调用次数比乘法还多。sq 的项数约为 mul 的一半，这点优化在 GPU 上每秒要兑现上千万次。

另外注意梯子里的常数乘也顺手写了（接在 `sq` 后面）：

```rust
/// 乘以 121665（Montgomery 梯子中的 a24）。
/// 注意：结果的 limb 会达到 2^45 左右，调用方在继续参与乘加前应先 carry。
pub fn mul121665(f: &Fe) -> Fe {
    let mut h = [0u64; 10];
    for i in 0..10 {
        h[i] = f.0[i] * 121665;
    }
    Fe(h)
}
```

⚠️ 它**不做 carry**（调用方自己负责，见 4.8 节），因为紧跟着的用法是相加后再归约，省一次进位。
