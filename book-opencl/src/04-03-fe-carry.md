# 4.3 fe.rs：carry 进位

这节写 `fe.rs` 里最短但最关键的函数 `carry`：把超标的 limb 逐级进位，顶端按 2²⁵⁵ ≡ 19 折回。原理在 3.4 节讲过，这里直接上代码。

## 代码

打开 `src/fe.rs`，把下面这段插在 `impl Fe { ... }` 块之后、`add` 函数之前（最终文件里 `carry` 就在这个位置）：

```rust
/// 弱归约：依次把每个 limb 超出的部分进位到下一个 limb，
/// limb9 的进位乘以 19 回到 limb0（因为 2^255 ≡ 19 mod p）。
pub fn carry(h: &Fe) -> Fe {
    let mut v = h.0;
    let mut c: u64;
    c = v[0] >> 26; v[1] += c; v[0] &= M26;
    c = v[1] >> 25; v[2] += c; v[1] &= M25;
    c = v[2] >> 26; v[3] += c; v[2] &= M26;
    c = v[3] >> 25; v[4] += c; v[3] &= M25;
    c = v[4] >> 26; v[5] += c; v[4] &= M26;
    c = v[5] >> 25; v[6] += c; v[5] &= M25;
    c = v[6] >> 26; v[7] += c; v[6] &= M26;
    c = v[7] >> 25; v[8] += c; v[7] &= M25;
    c = v[8] >> 26; v[9] += c; v[8] &= M26;
    c = v[9] >> 25; v[0] += 19 * c; v[9] &= M25;
    c = v[0] >> 26; v[1] += c; v[0] &= M26;
    Fe(v)
}
```

## 逐行读

拿第一行当样板，其余同构：

- `c = v[0] >> 26`：右移 26 位，取出 limb0 超出 26 bit 的部分（高位）；
- `v[1] += c`：这部分权重正好是 limb1 的单位（limb1 权重 = 2²⁶），进给它；
- `v[0] &= M26`：limb0 只保留低 26 bit。

偶数 limb 用 26、奇数用 25，交替到 limb9。然后两行特别的：

- `c = v[9] >> 25; v[0] += 19 * c; ...`：limb9 溢出的部分权重是 2²⁵⁵ 的倍数，按 2²⁵⁵ ≡ 19 乘 19 折回 limb0；
- 最后一行：折回可能让 limb0 又超标，**再进一次位收尾**（这次折回最多 19 倍左右，limb1 不可能再溢出，所以到这里一定收敛）。

> 💡 补给：`>>` 是右移（除以 2ⁿ 取整），`&` 是按位与。`x & ((1<<26)-1)` 就是「只留低 26 位」，因为 `(1<<26)-1` 的二进制是 26 个 1。这两个运算是本章的全部位操作。

## 为什么叫「弱归约」

carry 之后每个 limb 都在位数内，但整个数的**值**可能还 ≥ p（比如 v = p 本身，limb 全部合法）。没关系——继续参与 add/mul 都正确，反正最后 `to_bytes` 会做强归约（4.7 节）。

## 小结

`carry` 是连接各运算的「清道夫」：mul/sq 出口处必调用。下一节写乘法，看完你会发现它出口处果然是 `carry(&Fe([...]))`。
