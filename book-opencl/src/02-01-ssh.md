# 2.1 ssh 登录 GPU 主机

这节搞定第一件事：从你自己的电脑登录到那台带 GPU 的 Linux 主机。本书后续所有命令都在这台主机上执行。

## 最基础的登录

假设主机在内网的 IP 是 `192.168.1.50`，你的用户名是 `alice`：

```console
$ ssh alice@192.168.1.50
```

输入密码后就进去了。之后书里出现的所有命令，都是在这个 ssh 会话里敲的。

> 💡 补给：ssh 是「在你自己电脑的终端里，操作远程主机的 shell」。你敲的命令在远程主机上执行，文本结果传回来显示。GPU 主机的显存、算力都在那边，你的笔记本只负责打字。

## 免记 IP：~/.ssh/config

每次敲 `ssh alice@192.168.1.50` 很烦，在自己电脑的 `~/.ssh/config` 里加一段：

```sshconfig
Host gpu
    HostName 192.168.1.50
    User alice
```

以后只需要：

```console
$ ssh gpu
```

> 💡 补给：`~/.ssh/config` 是 ssh 客户端的配置文件，`Host gpu` 是你自己起的别名；`HostName` 写真实地址，`User` 写登录用户名。文件不存在就自己新建一个。

## 免输密码：密钥登录（可选但推荐）

在自己电脑上：

```console
$ ssh-keygen -t ed25519        # 一路回车
$ ssh-copy-id gpu              # 把公钥装到主机上，这一步要输一次密码
$ ssh gpu                      # 之后不再需要密码
```

登录成功后，先确认一下显卡在场（2.4 节会正式验证驱动，这里只是看看硬件）：

```console
$ lspci | grep -i vga
03:00.0 VGA compatible controller: Advanced Micro Devices, Inc. [AMD/ATI] Navi 31 [Radeon RX 7900 XT/7900 XTX]
```

能看到类似的一行，就可以进入下一节了。
