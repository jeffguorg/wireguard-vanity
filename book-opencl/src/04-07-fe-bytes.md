# 4.7 fe.rs：to_bytes / from_bytes

这节写 `fe.rs` 的最后两个函数：32 字节（小端序）和 limb 数组之间的互相转换。`to_bytes` 里还藏着全文件唯一一次**强归约**。

## from_bytes：字节解包成 limb

```rust
/// 从 32 字节小端序解包（忽略第 256 位）。
pub fn from_bytes(s: &[u8; 32]) -> Fe {
    let load3 = |s: &[u8]| -> u64 { s[0] as u64 | (s[1] as u64) << 8 | (s[2] as u64) << 16 };
    let load4 = |s: &[u8]| -> u64 {
        s[0] as u64 | (s[1] as u64) << 8 | (s[2] as u64) << 16 | (s[3] as u64) << 24
    };
    let h = [
        load4(&s[0..]),
        load3(&s[4..]) << 6,
        load3(&s[7..]) << 5,
        load3(&s[10..]) << 3,
        load3(&s[13..]) << 2,
        load4(&s[16..]),
        load3(&s[20..]) << 7,
        load3(&s[23..]) << 5,
        load3(&s[26..]) << 4,
        (load3(&s[29..]) & 0x7f_ffff) << 2,
    ];
    carry(&Fe(h))
}
```

读法：limb 权重依次是 2⁰、2²⁶、2⁵¹、2⁷⁷……换成字节边界是 0、3.25、6.375……不整除 8，所以每个 limb 都是「从某个字节偏移处取 3～4 字节、左移几个零碎 bit」。那些 `<< 6`、`<< 5` 就是把上一 limb 没对齐的余量补上。不用手推，信任 ref10 的表、照抄。

> 💡 补给：`let load3 = |s: &[u8]| -> u64 { ... };` 是闭包（匿名函数），赋给变量后像函数一样调用。`s[0] as u64` 是类型转换。字节序上这是**小端**（little-endian）：低字节在前，`s[0]` 是最低位——WireGuard/RFC 7748 的规定。

## to_bytes：强归约 + 打包

```rust
/// 强归约并打包为 32 字节小端序。
pub fn to_bytes(h: &Fe) -> [u8; 32] {
    // 先做一次弱归约，让 limb 都在位数范围内
    let mut v = carry(h).0;

    // 计算 q = floor((v + 19) / 2^255)，即 v 是否 >= p。
    // 若 q=1，则 v + 19 会越过 2^255，下面 v[0] += 19q 再进位的效果
    // 等同于减去 p。
    let mut q = (19 * v[9] + (1 << 24)) >> 25;
    q = (v[0] + q) >> 26;
    q = (v[1] + q) >> 25;
    q = (v[2] + q) >> 26;
    q = (v[3] + q) >> 25;
    q = (v[4] + q) >> 26;
    q = (v[5] + q) >> 25;
    q = (v[6] + q) >> 26;
    q = (v[7] + q) >> 25;
    q = (v[8] + q) >> 26;
    q = (v[9] + q) >> 25;

    v[0] += 19 * q;
    // 最终进位链：最高 limb 溢出的位代表 q·2^255，直接丢弃（不能再 ×19 折回）
    let mut c: u64;
    c = v[0] >> 26; v[1] += c; v[0] &= M26;
    c = v[1] >> 25; v[2] += c; v[1] &= M25;
    c = v[2] >> 26; v[3] += c; v[2] &= M26;
    c = v[3] >> 25; v[4] += c; v[3] &= M25;
    c = v[4] >> 26; v[5] += c; v[4] &= M26;
    c = v[5] >> 25; v[6] += c; v[5] &= M25;
    c = v[6] >> 26; v[7] += c; v[6] &= M26;
    c = v[7] >> 25; v[8] += c; v[7] &= M25;
    c = v[8] >> 26; v[9] += c; v[8] &= M26;
    v[9] &= M25;

    // 打包：26/25 bit limb 交错拼回字节流
    let mut s = [0u8; 32];
    s[0] = (v[0]) as u8;
    s[1] = (v[0] >> 8) as u8;
    s[2] = (v[0] >> 16) as u8;
    s[3] = ((v[0] >> 24) | (v[1] << 2)) as u8;
    s[4] = (v[1] >> 6) as u8;
    s[5] = (v[1] >> 14) as u8;
    s[6] = ((v[1] >> 22) | (v[2] << 3)) as u8;
    s[7] = (v[2] >> 5) as u8;
    s[8] = (v[2] >> 13) as u8;
    s[9] = ((v[2] >> 21) | (v[3] << 5)) as u8;
    s[10] = (v[3] >> 3) as u8;
    s[11] = (v[3] >> 11) as u8;
    s[12] = ((v[3] >> 19) | (v[4] << 6)) as u8;
    s[13] = (v[4] >> 2) as u8;
    s[14] = (v[4] >> 10) as u8;
    s[15] = (v[4] >> 18) as u8;
    s[16] = (v[5]) as u8;
    s[17] = (v[5] >> 8) as u8;
    s[18] = (v[5] >> 16) as u8;
    s[19] = ((v[5] >> 24) | (v[6] << 1)) as u8;
    s[20] = (v[6] >> 7) as u8;
    s[21] = (v[6] >> 15) as u8;
    s[22] = ((v[6] >> 23) | (v[7] << 3)) as u8;
    s[23] = (v[7] >> 5) as u8;
    s[24] = (v[7] >> 13) as u8;
    s[25] = ((v[7] >> 21) | (v[8] << 4)) as u8;
    s[26] = (v[8] >> 4) as u8;
    s[27] = (v[8] >> 12) as u8;
    s[28] = ((v[8] >> 20) | (v[9] << 6)) as u8;
    s[29] = (v[9] >> 2) as u8;
    s[30] = (v[9] >> 10) as u8;
    s[31] = (v[9] >> 18) as u8;
    s
}
```

## q 技巧：无分支地「减 p」

弱归约后的值在 [0, 2p) 里，规范输出要求 [0, p)。直接 `if v >= p { v -= p }` 又会引入分支和大数比较。ref10 的 q 技巧：

1. 算 `q = floor((v + 19) / 2²⁵⁵)`：把 19 从顶端加进去、一路进位，溢出来的那个 bit 就是 q。v ≥ p 时 v+19 ≥ 2²⁵⁵，q = 1，否则 q = 0；
2. `v[0] += 19*q` 再进位：q=1 时等于加了 19、顶端溢出被**直接丢弃**（不再 ×19 折回！），净效果 = v + 19 − 2²⁵⁵ = v − p；q=0 时什么都没发生。

注意注释的提醒：最终进位链顶端**不**做 ×19 折回，这正是「减 p」生效的地方。

打包部分是把 26/25 bit 的 limb 按小端序拼回字节流，`as u8` 只保留低 8 位。同样照抄即可。
