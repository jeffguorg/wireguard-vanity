## 文件头与命令行解析

用下面内容**整体替换** `src/main.rs`（还没写完，后续三节继续往里加）：

```rust
//! WireGuard 公钥前缀搜索（OpenCL 版）宿主程序。
//!
//! 用法:
//!   wg-vanity-opencl <前缀> [--count N] [--round-log2 N] [--selftest [N]]
//!
//! 例:
//!   wg-vanity-opencl Hello          # 找第一个公钥以 "Hello" 开头的密钥对
//!   wg-vanity-opencl Hi --count 3   # 找 3 个
//!   wg-vanity-opencl --selftest     # GPU 与 curve25519-dalek 对拍 4096 个密钥

mod fe;
mod keygen;
mod prefix;
mod x25519;

use std::ptr;
use std::time::{Instant, SystemTime, UNIX_EPOCH};

use base64::{engine::general_purpose::STANDARD, Engine as _};
use opencl3::command_queue::CommandQueue;
use opencl3::context::Context;
use opencl3::device::{get_all_devices, CL_DEVICE_TYPE_GPU};
use opencl3::kernel::{ExecuteKernel, Kernel};
use opencl3::memory::{Buffer, CL_MEM_READ_ONLY, CL_MEM_READ_WRITE};
use opencl3::program::Program;
use opencl3::types::{cl_uint, cl_ulong, CL_BLOCKING};

const KERNEL_SRC: &str = include_str!("../kernel.cl");
/// 每轮最多回收的命中数量（与 kernel 中 slot < 64 对应）
const MAX_HITS: usize = 64;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut prefix_arg: Option<String> = None;
    let mut count: usize = 1;
    let mut round_log2: u32 = 22; // 每轮 2^22 ≈ 4M 个候选
    let mut selftest: Option<usize> = None;

    let mut args = std::env::args().skip(1).peekable();
    while let Some(a) = args.next() {
        match a.as_str() {
            "--count" => count = args.next().ok_or("--count 需要参数")?.parse()?,
            "--round-log2" => round_log2 = args.next().ok_or("--round-log2 需要参数")?.parse()?,
            "--selftest" => {
                // 可选的数字参数：仅当下一个参数能解析为数字时消费它
                let n = args
                    .next_if(|s| s.parse::<usize>().is_ok())
                    .map(|s| s.parse().unwrap())
                    .unwrap_or(4096);
                selftest = Some(n);
            }
            "--help" | "-h" => {
                println!("用法: wg-vanity-opencl <前缀> [--count N] [--round-log2 N] [--selftest [N]]");
                return Ok(());
            }
            s if s.starts_with('-') => return Err(format!("未知参数 {s}").into()),
            s => prefix_arg = Some(s.to_string()),
        }
    }
```


> ⚠️ 注意：到 7.4 节写完 `run_selftest` 之前，`cargo build` 都会报错——先是 `fn main` 一直没有右括号（7.2、7.3 两节会继续往里加代码），main 闭合后又会因为 `run_selftest` 尚未定义报 `cannot find function`。这是正常的，别回头改代码。
## 要点

- `include_str!("../kernel.cl")`：**编译期**把 kernel.cl 的文本嵌进可执行文件，运行时不用再找文件路径；
- `KERNEL_SRC` 是 `&'static str`，直接喂给 OpenCL 编译器（7.2 节）；
- `MAX_HITS = 64` 必须和 kernel 里的 `slot < 64` 一致——两边是同一个约定的两端。

## 参数解析的设计

手写解析而不用 clap 库：一共就三个选项。`--selftest` 的参数是可选的（`--selftest` 和 `--selftest 8192` 都合法），这是唯一的难点，用 `peekable` 解决：先偷看下一个参数，能解析成数字才消费它。

> 💡 补给：`peekable()` 把迭代器包装成「能偷看」的版本。`next_if(f)` = 看一眼队首，满足条件 f 才取出，否则原地不动。`Option` 的 `.map(f).unwrap_or(d)` 链：有值就变换，没值用默认。`match` 里 `s if s.starts_with('-')` 是带守卫的分支：匹配任意字符串但要求以 `-` 开头。

> 💡 补给：`fn main() -> Result<(), Box<dyn std::error::Error>>`：main 可以返回 Result，出错时 Rust 打印错误并退出码非零。`Box<dyn Error>` 是「任何错误类型的盒子」，让我们能对不同类型的错误统一用 `?`。
