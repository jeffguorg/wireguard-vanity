# 3.6 费马小定理求逆与加法链

这节讲梯子的收尾：怎么在模 p 下算「除法」，即求 z⁻¹。答案是一条固定的「加法链」：254 次平方 + 11 次乘法。

## 用费马小定理把除法变乘法

有限域里没有除法，除以 z 就是乘以 z 的逆元 z⁻¹。费马小定理说：对任意非零 z，

```text
z^(p-1) ≡ 1  (mod p)   ⇒   z^(p-2) ≡ z⁻¹  (mod p)
```

所以求逆 = 计算 z 的 (p−2) 次幂。p−2 = 2²⁵⁵ − 21，一个 255 bit 的指数。 naive 地乘 2²⁵⁵ 次当然不行，要用「平方-乘」：比如 z⁸ = ((z²)²)²，三次平方搞定。

## 加法链：把指数拆成流水线

「平方-乘」的通用版是按指数的二进制位逐位处理，约 255 平方 + 128 乘法。但指数 p−2 是**固定常数**，可以为它手工设计一条更优的计算路线，这就是加法链。核心技巧是下面这个递推：

```text
已有 z^(2^a − 1)：
    平方 b 次  →  z^(2^b·(2^a−1)) = z^(2^(a+b) − 2^b)
    再乘 z^(2^b − 1)  →  z^(2^(a+b) − 1)
```

「全 1 二进制」的指数可以像滚雪球一样翻倍变大：1 → 3 → 7 → 15 …… 即 z^(2ⁿ−1) 家族。ref10 的链就是一路滚出 z^(2²⁵⁰−1)，再平方 5 次、乘上开头攒下的 z¹¹：

```text
z^(2^250 − 1) ──平方5次──► z^(2^255 − 32) ──× z^11──► z^(2^255 − 21) = z^(p−2) ✓
```

> 💡 补给：「加法链」这个名字的由来：求 zⁿ 相当于用「从 1 出发、每步把已有两个数相加（对应幂相乘）」的方式凑出 n。链越短，乘法次数越少。2²⁵⁵−21 这条链是 ref10 沿用多年的固定答案，254 平方 + 11 乘法，直接抄，不用自己发明。

## 代码怎么读

4.6 节的 `invert` 函数里，每一段都是同一个句式：

```rust
let mut t2 = sq(&t1);
for _ in 1..5 {
    t2 = sq(&t2);
}
let t1 = mul(&t2, &t1); // z^(2^10 - 1)
```

=「平方 5 次（1 + 循环 4 次），再乘回去」，即滚雪球的一步。行尾注释标出了当前算到了 z 的多少次幂，对照本节就能逐行读懂。

## 小结

- 求逆 = z^(p−2)，费马小定理白送；
- 固定指数 → 固定加法链，254 sq + 11 mul 一次搞定；
- 每个候选密钥只做一次求逆，但它抵得上小半个梯子的开销，值得用最优链。
