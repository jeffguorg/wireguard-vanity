# 2.2 在远程主机上编辑文件

代码要写在 GPU 主机上，但编辑器不一定非得是终端里的。这节给两种方案，任选其一。

## 方案一（推荐）：VS Code + Remote-SSH

在自己电脑上装 VS Code，再装 **Remote-SSH** 插件。左下角点绿色按钮 →「Connect to Host」→ 选 2.1 节配好的别名 `gpu`（ssh config 里的 Host 会被插件直接认出来）。

连上之后，「打开文件夹」选主机上的目录，之后编辑、保存、开终端跑 `cargo`，体验和本地开发完全一样——文件实际都在 GPU 主机上，VS Code 只是透过 ssh 操作它们。

## 方案二：终端里的 nano

不想装 VS Code 的话，主机上装个最简单的编辑器：

```console
$ sudo pacman -S nano
```

三个键就够本书用了：

| 键 | 作用 |
|---|---|
| `Ctrl+O` | 保存（WriteOut，回车确认文件名） |
| `Ctrl+X` | 退出 |
| `Ctrl+W` | 搜索 |

> 💡 补给：本书所有代码都在 GPU 主机上编辑——`cargo`、`clinfo`、GPU 都在那边，文件放别处反而要来回传。ssh 断线只断开你的会话，**已保存的文件不受影响**，重新连上接着干就行。
