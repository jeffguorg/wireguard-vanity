# 4.6 fe.rs：invert

这节写域求逆 `invert`：z⁻¹ = z^(p−2)，用 3.6 节讲的 ref10 加法链。代码是一段段「平方 k 次、乘一次」的重复，读法统一。

## 代码

接在 `mul121665` 后面：

```rust
/// 逆元：z^(p-2) = z^(2^255 - 21)（费马小定理）。
/// 使用 ref10 的固定加法链，共 254 次平方 + 11 次乘法。
pub fn invert(z: &Fe) -> Fe {
    let t0 = sq(z); // z^2
    let mut t1 = sq(&t0);
    t1 = sq(&t1); // z^8
    t1 = mul(z, &t1); // z^9
    let t0 = mul(&t0, &t1); // z^11
    let t2 = sq(&t0); // z^22
    let t1 = mul(&t1, &t2); // z^31 = z^(2^5 - 1)

    let mut t2 = sq(&t1);
    for _ in 1..5 {
        t2 = sq(&t2);
    }
    let t1 = mul(&t2, &t1); // z^(2^10 - 1)

    let mut t2 = sq(&t1);
    for _ in 1..10 {
        t2 = sq(&t2);
    }
    let t2 = mul(&t2, &t1); // z^(2^20 - 1)

    let mut t3 = sq(&t2);
    for _ in 1..20 {
        t3 = sq(&t3);
    }
    let t2 = mul(&t3, &t2); // z^(2^40 - 1)

    let mut t2 = sq(&t2);
    for _ in 1..10 {
        t2 = sq(&t2);
    }
    let t1 = mul(&t2, &t1); // z^(2^50 - 1)

    let mut t2 = sq(&t1);
    for _ in 1..50 {
        t2 = sq(&t2);
    }
    let t2 = mul(&t2, &t1); // z^(2^100 - 1)

    let mut t3 = sq(&t2);
    for _ in 1..100 {
        t3 = sq(&t3);
    }
    let t2 = mul(&t3, &t2); // z^(2^200 - 1)

    let mut t2 = sq(&t2);
    for _ in 1..50 {
        t2 = sq(&t2);
    }
    let t1 = mul(&t2, &t1); // z^(2^250 - 1)

    let mut t1 = sq(&t1);
    for _ in 1..5 {
        t1 = sq(&t1);
    }
    mul(&t1, &t0) // z^(2^255 - 21)
}
```

## 加法链怎么读

行尾注释就是指数。跟着滚一遍雪球：

1. 开头四行凑出 `z^9` 和 `z^11`（t0 留到最后收尾巴用）；
2. `t2 = sq(&t0); t1 = mul(&t1, &t2);` 得 z²²·z⁹ = z³¹ = z^(2⁵−1)——第一颗雪球；
3. 之后每段同一个句式：平方 k 次（`sq` 一次 + 循环 `1..k` 次），再乘回上一颗雪球：z^(2⁵−1) → z^(2¹⁰−1) → z^(2²⁰−1) → z^(2⁴⁰−1) → z^(2⁵⁰−1) → z^(2¹⁰⁰−1) → z^(2²⁰⁰−1) → z^(2²⁵⁰−1)；
4. 最后平方 5 次得 z^(2²⁵⁵−32)，乘上开头攒的 z¹¹：z^(2²⁵⁵−21) = z^(p−2) ✓。

数一遍：254 次平方 + 11 次乘法，与注释相符。

> 💡 补给：`for _ in 1..5` 循环 4 次（区间左闭右开），`_` 表示「循环变量不用」。加上循环前那一次 `sq`，总共平方 5 次。`let mut t2 = ...` 里的 `mut` 表示变量可重新赋值；后面的 `let t2 = mul(...)` 是**遮蔽**（shadowing）：声明一个同名新变量，旧的作废，类型都允许变。
