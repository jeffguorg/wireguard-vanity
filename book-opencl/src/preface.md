# 前言

这本书带你从零写出一个能跑的 GPU 程序：用显卡暴力搜索一个「公钥带指定前缀」的 WireGuard 密钥对（vanity 公钥）。比如你想要一个以 `Hello` 开头的公钥，程序会每秒尝试上千万个密钥，直到撞出来为止。

## 最终成果

跟着书敲完，你会得到一个命令行程序 `wg-vanity-opencl`：

```console
$ cargo run --release -- Hello --count 1
私钥: 0Jrr...（base64，44 字符）
公钥: Hello...（base64，44 字符）
```

私钥可以直接填进 WireGuard 配置，公钥就是你要的那个「好看的公钥」。

一路上你会亲手写出三样东西：

1. **CPU 参考实现**（Rust）：GF(2^255-19) 有限域运算 + X25519，用 RFC 7748 测试向量和 curve25519-dalek 验证正确性；
2. **GPU kernel**（OpenCL C）：把同一套算法逐行移植到显卡上；
3. **宿主程序**（Rust + opencl3）：负责喂参数、发射 kernel、回收命中的密钥。

## 需要什么样的机器

- 一台装着 **AMD GPU** 的 Linux 主机（书里以 Arch Linux + RX 7900 XTX 为例，包管理用 `pacman`）。其他支持 OpenCL 的 AMD 卡也可以；
- 你从自己的电脑 **ssh** 到这台主机上操作（2.1 节会讲怎么配）；
- 不需要显示器、不需要桌面环境。

## 你需要会什么

会基础 Rust 就够了：`cargo new`、写 `fn` 和 `struct`、知道所有权大概是怎么回事。**不需要**懂 GPU 编程、椭圆曲线密码学、OpenCL——这些都会在第 3 章和第 5 章补齐。新手容易卡住的语法点（`?`、`unsafe`、迭代器、位运算……）会在用到的地方用「💡 补给」小段就地解释。

## 怎么读这本书

第 4、6、7 章是动手部分：**打开编辑器跟着敲**，书中的每一段代码都是最终可运行项目的真实代码，逐段拼起来就是完整文件。其余章节以解释为主，读懂即可。

> 💡 补给：本书对应仓库 `wireguard-vanity` 的 `opencl/` 目录。卡壳时可以对照仓库里的最终文件检查自己敲的代码。
