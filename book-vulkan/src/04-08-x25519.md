# 4.8 x25519.rs：clamp 与梯子

这节写 `src/x25519.rs` 的非测试部分：cswap、clamp、梯子主循环。3.5 节的理论在这里落成代码。

## 文件头、cswap 与 clamp

```rust
//! X25519（RFC 7748）： Montgomery 梯子 + 域求逆，只支持基点（u=9）。
//!
//! WireGuard 只需要 `X25519(私钥, 基点)`，所以不需要处理任意 u 坐标。

use crate::fe::{self, Fe};

/// 常数时间条件交换：swap=1 时交换 a、b，swap=0 时不变。
/// 用掩码而非分支实现（GPU 上也便宜）。
fn cswap(swap: u64, a: &mut Fe, b: &mut Fe) {
    let mask = 0u64.wrapping_sub(swap);
    for i in 0..10 {
        let t = mask & (a.0[i] ^ b.0[i]);
        a.0[i] ^= t;
        b.0[i] ^= t;
    }
}

/// 对 32 字节私钥做 RFC 7748 规定的 clamp。
pub fn clamp(k: &mut [u8; 32]) {
    k[0] &= 248;
    k[31] &= 127;
    k[31] |= 64;
}
```

`0u64.wrapping_sub(swap)`：swap=1 时 0−1 回绕成全 1 的掩码，swap=0 时是 0——3.5 节讲的掩码技巧。`&mut Fe` 表示可变借用：函数可以改调用方的两个 `Fe`。

## 两个入口

```rust
/// X25519(scalar, u)，通用形式。
pub fn x25519_with_u(scalar: &[u8; 32], u: &[u8; 32]) -> [u8; 32] {
    x25519_impl(scalar, &fe::from_bytes(u))
}

/// X25519(scalar, 基点 9)，返回公钥的 32 字节小端序。
pub fn x25519_base(scalar: &[u8; 32]) -> [u8; 32] {
    // 基点 u 坐标 = 9
    x25519_impl(scalar, &Fe([9, 0, 0, 0, 0, 0, 0, 0, 0, 0]))
}
```

WireGuard 只用 `x25519_base`；`x25519_with_u` 存在的主要理由是 RFC 7748 的迭代测试向量需要任意 u（4.9 节会用到）。

## 梯子主循环

```rust
fn x25519_impl(scalar: &[u8; 32], x1: &Fe) -> [u8; 32] {
    let mut s = *scalar;
    clamp(&mut s);

    let x1 = *x1;
    let mut x2 = Fe::ONE;
    let mut z2 = Fe::ZERO;
    let mut x3 = x1;
    let mut z3 = Fe::ONE;

    let mut swap: u64 = 0;
    // 从高到低扫描 scalar 的 254..=0 位
    for t in (0..255).rev() {
        let bit = ((s[t / 8] >> (t & 7)) & 1) as u64;
        swap ^= bit;
        cswap(swap, &mut x2, &mut x3);
        cswap(swap, &mut z2, &mut z3);
        swap = bit;

        let a = fe::add(&x2, &z2);
        let aa = fe::sq(&a);
        let b = fe::sub(&x2, &z2);
        let bb = fe::sq(&b);
        let e = fe::sub(&aa, &bb);
        let c = fe::add(&x3, &z3);
        let d = fe::sub(&x3, &z3);
        let da = fe::mul(&d, &a);
        let cb = fe::mul(&c, &b);
        let da_plus_cb = fe::add(&da, &cb);
        let da_minus_cb = fe::sub(&da, &cb);

        x3 = fe::sq(&da_plus_cb);
        z3 = fe::mul(&x1, &fe::sq(&da_minus_cb));
        x2 = fe::mul(&aa, &bb);
        // z2 = E * (AA + a24 * E)，mul121665 的结果 limb 较大，先归约再参与运算
        z2 = fe::mul(&e, &fe::add(&aa, &fe::carry(&fe::mul121665(&e))));
    }
    cswap(swap, &mut x2, &mut x3);
    cswap(swap, &mut z2, &mut z3);

    // u = x2 / z2 = x2 * z2^(p-2)
    fe::to_bytes(&fe::mul(&x2, &fe::invert(&z2)))
}
```

对照 3.5 节：(x2, z2) 与 (x3, z3) 是投影坐标下的两个「相差一格」的点；`swap ^= bit; cswap(...); swap = bit` 是 RFC 7748 规定的惰性交换模式——用上一轮和这一轮位的异或决定换不换。注意 z2 那一行的 `fe::carry(&fe::mul121665(&e))`：4.5 节警告过的 limb 超标，在这里 carry 掉。

`s[t / 8] >> (t & 7) & 1` 逐位取私钥（小端字节内也是低位先取，对应 t 从 254 往 0 扫）。循环结束后两个 cswap 收尾，最后 `x2 · invert(z2)` 转回普通坐标、打包输出。
