# 4.4 fe.rs：mul

这节写域乘法——整个项目里单条最复杂的函数，也是 3.4 节「折叠规则」的集中应用。照敲即可，注释里已经把系数规则写清。

## 系数规则回顾

v[i]·v[j] 落到目标 limb 时只有三种情况：直接落入（系数 1）、跨过 2^255 折回（系数 19）、奇×奇 limb 差一个因子 2（直接项 2、折回项 38）。ref10 的写法把 ×2 并进 f 的奇 limb（`f1_2` 等）、×19 并进 g（`g1_19` 等），我们沿用。

## 代码

接在 `sub` 之后：

```rust
/// 乘法（课本式 + 折叠）。
///
/// 关键规则（由 limb 权重推出）：
/// - i+j = k：直接落入 limb k，系数 1；
/// - i+j = k+10：相当于乘以 2^255 ≡ 19，折叠回 limb k，系数 19；
/// - 奇数 limb × 奇数 limb 的权重比预期多一个因子 2，
///   所以 odd×odd 的直接项系数 2、折叠项系数 38。
/// ref10 的实现把 "×2" 并进 f 的奇数 limb（f1_2 = 2*f1 等）、
/// 把 "×19" 并进 g（g1_19 = 19*g1 等），下面沿用同一写法。
pub fn mul(f: &Fe, g: &Fe) -> Fe {
    let [f0, f1, f2, f3, f4, f5, f6, f7, f8, f9] = f.0;
    let [g0, g1, g2, g3, g4, g5, g6, g7, g8, g9] = g.0;

    let f1_2 = 2 * f1;
    let f3_2 = 2 * f3;
    let f5_2 = 2 * f5;
    let f7_2 = 2 * f7;
    let f9_2 = 2 * f9;

    let g1_19 = 19 * g1;
    let g2_19 = 19 * g2;
    let g3_19 = 19 * g3;
    let g4_19 = 19 * g4;
    let g5_19 = 19 * g5;
    let g6_19 = 19 * g6;
    let g7_19 = 19 * g7;
    let g8_19 = 19 * g8;
    let g9_19 = 19 * g9;

    let h0 = f0 * g0
        + f1_2 * g9_19 + f2 * g8_19 + f3_2 * g7_19 + f4 * g6_19 + f5_2 * g5_19
        + f6 * g4_19 + f7_2 * g3_19 + f8 * g2_19 + f9_2 * g1_19;
    let h1 = f0 * g1 + f1 * g0
        + f2 * g9_19 + f3 * g8_19 + f4 * g7_19 + f5 * g6_19 + f6 * g5_19
        + f7 * g4_19 + f8 * g3_19 + f9 * g2_19;
    let h2 = f0 * g2 + f1_2 * g1 + f2 * g0
        + f3_2 * g9_19 + f4 * g8_19 + f5_2 * g7_19 + f6 * g6_19 + f7_2 * g5_19
        + f8 * g4_19 + f9_2 * g3_19;
    let h3 = f0 * g3 + f1 * g2 + f2 * g1 + f3 * g0
        + f4 * g9_19 + f5 * g8_19 + f6 * g7_19 + f7 * g6_19 + f8 * g5_19 + f9 * g4_19;
    let h4 = f0 * g4 + f1_2 * g3 + f2 * g2 + f3_2 * g1 + f4 * g0
        + f5_2 * g9_19 + f6 * g8_19 + f7_2 * g7_19 + f8 * g6_19 + f9_2 * g5_19;
    let h5 = f0 * g5 + f1 * g4 + f2 * g3 + f3 * g2 + f4 * g1 + f5 * g0
        + f6 * g9_19 + f7 * g8_19 + f8 * g7_19 + f9 * g6_19;
    let h6 = f0 * g6 + f1_2 * g5 + f2 * g4 + f3_2 * g3 + f4 * g2 + f5_2 * g1 + f6 * g0
        + f7_2 * g9_19 + f8 * g8_19 + f9_2 * g7_19;
    let h7 = f0 * g7 + f1 * g6 + f2 * g5 + f3 * g4 + f4 * g3 + f5 * g2 + f6 * g1 + f7 * g0
        + f8 * g9_19 + f9 * g8_19;
    let h8 = f0 * g8 + f1_2 * g7 + f2 * g6 + f3_2 * g5 + f4 * g4
        + f5_2 * g3 + f6 * g2 + f7_2 * g1 + f8 * g0 + f9_2 * g9_19;
    let h9 = f0 * g9 + f1 * g8 + f2 * g7 + f3 * g6 + f4 * g5
        + f5 * g4 + f6 * g3 + f7 * g2 + f8 * g1 + f9 * g0;

    carry(&Fe([h0, h1, h2, h3, h4, h5, h6, h7, h8, h9]))
}
```

## 怎么检查自己敲对了

以 h2 为例心算：i+j=2 的直接项是 f0g2、f1g1、f2g0（f1g1 是奇×奇，系数 2 → `f1_2 * g1`）；折回项是 i+j=12 的组合（f3g9、f4g8、…），其中奇×奇（f3g9、f5g7、f7g5、f9g3）系数 38 = 2×19 → 写成 `f3_2 * g9_19`，偶×偶（f4g8、f6g6、f8g4）系数 19 → `f4 * g8_19`。每条 h 行都遵守这个模式，对不上就是抄错了。

开头两行 `let [f0, ...] = f.0;` 是数组解构，把 10 个 limb 解成局部变量——纯粹为了让后面 100 个乘项写得短。

💡 **补给：为什么不溢出。** 别按「limb ≤ 2^28」估——那是纪律红线，不是实际值。实际上界这样推：carry 后 limb < 2^26/2^25（偶/奇），一次加减最多翻几倍（sub 会先垫 2p），所以进 mul/sq 的 limb ≲ 2^27.6，单个乘积 ≲ 2^55.2。系数最大的一行是 h0，合计 267 ≈ 2^8.1（多数项系数是 1，19/38 只出现在折叠项和奇×奇项），于是 h0 ≲ 2^55.2 × 2^8.1 ≈ 2^63.3，离 u64 的 2^64 上限还有余量——安全。这正是「进 mul/sq 前必须 carry」这条纪律存在的意义，也是 ref10 选 26/25 而不是 26/26 的原因。

最后调一次 `carry` 收尾，保证输出的 limb 回到位宽内。
