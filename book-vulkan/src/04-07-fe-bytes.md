# 4.7 fe.rs：to_bytes / from_bytes

这节写 `fe.rs` 的最后两块：字节流和 limb 数组之间的双向转换。`from_bytes` 用于读入 u 坐标，`to_bytes` 用于输出公钥——后者还包含 3.4 节说的强归约。

## from_bytes：小端字节流 → limb

```rust
/// 从 32 字节小端序解包（忽略第 256 位）。
pub fn from_bytes(s: &[u8; 32]) -> Fe {
    let load3 = |s: &[u8]| -> u64 { s[0] as u64 | (s[1] as u64) << 8 | (s[2] as u64) << 16 };
    let load4 = |s: &[u8]| -> u64 {
        s[0] as u64 | (s[1] as u64) << 8 | (s[2] as u64) << 16 | (s[3] as u64) << 24
    };
    let h = [
        load4(&s[0..]),
        load3(&s[4..]) << 6,
        load3(&s[7..]) << 5,
        load3(&s[10..]) << 3,
        load3(&s[13..]) << 2,
        load4(&s[16..]),
        load3(&s[20..]) << 7,
        load3(&s[23..]) << 5,
        load3(&s[26..]) << 4,
        (load3(&s[29..]) & 0x7f_ffff) << 2,
    ];
    carry(&Fe(h))
}
```

💡 **补给：闭包。** `let load3 = |s: &[u8]| -> u64 { ... }` 定义了一个匿名函数存进变量，后面 `load3(&s[4..])` 直接调用。闭包能捕获局部环境（这里不需要），用起来和普通函数一样。

💡 **补给：字节序（endianness）。** 小端序 = 最低位字节排在最前。`s[0] | s[1]<<8 | s[2]<<16` 就是把前 3 个字节按小端拼成整数。RFC 7748 规定 X25519 的字节流是小端，全书（CPU、GLSL、`wg` 命令）统一遵守。

因为 limb 边界（26/25 bit）不和字节边界（8 bit）对齐，所以每个 limb 要「取 3~4 字节再左移补齐」。最后的 `<< 2` 配 `& 0x7f_ffff` 是忽略第 256 位：RFC 允许输入的最高位是任意值，直接丢弃。

## to_bytes：强归约 + 打包

分两段。第一段先弱归约，再算 q = ⌊(v + 19) / 2^255⌋（即 v 是否 ≥ p），若 q=1 则 v+19 会越过 2^255，于是 v[0] += 19q 再进位的效果等于减 p：

```rust
/// 强归约并打包为 32 字节小端序。
pub fn to_bytes(h: &Fe) -> [u8; 32] {
    // 先做一次弱归约，让 limb 都在位数范围内
    let mut v = carry(h).0;

    // 计算 q = floor((v + 19) / 2^255)，即 v 是否 >= p。
    // 若 q=1，则 v + 19 会越过 2^255，下面 v[0] += 19q 再进位的效果
    // 等同于减去 p。
    let mut q = (19 * v[9] + (1 << 24)) >> 25;
    q = (v[0] + q) >> 26;
    q = (v[1] + q) >> 25;
    q = (v[2] + q) >> 26;
    q = (v[3] + q) >> 25;
    q = (v[4] + q) >> 26;
    q = (v[5] + q) >> 25;
    q = (v[6] + q) >> 26;
    q = (v[7] + q) >> 25;
    q = (v[8] + q) >> 26;
    q = (v[9] + q) >> 25;

    v[0] += 19 * q;
    // 最终进位链：最高 limb 溢出的位代表 q·2^255，直接丢弃（不能再 ×19 折回）
    let mut c: u64;
    c = v[0] >> 26; v[1] += c; v[0] &= M26;
    c = v[1] >> 25; v[2] += c; v[1] &= M25;
    c = v[2] >> 26; v[3] += c; v[2] &= M26;
    c = v[3] >> 25; v[4] += c; v[3] &= M25;
    c = v[4] >> 26; v[5] += c; v[4] &= M26;
    c = v[5] >> 25; v[6] += c; v[5] &= M25;
    c = v[6] >> 26; v[7] += c; v[6] &= M26;
    c = v[7] >> 25; v[8] += c; v[7] &= M25;
    c = v[8] >> 26; v[9] += c; v[8] &= M26;
    v[9] &= M25;
```

注意和 `carry` 的差别：最后 `v[9] &= M25` 之后**没有**把溢出折回 limb0——那个溢出位正是要减掉的 q·2^255，丢掉它才完成「减 p」。这是全项目唯一一处「溢出是有意丢弃」的进位链。

第二段把 26/25 交错的 limb 拼回字节（左移拼接处对应 from_bytes 的逆操作）：

```rust
    // 打包：26/25 bit limb 交错拼回字节流
    let mut s = [0u8; 32];
    s[0] = (v[0]) as u8;
    s[1] = (v[0] >> 8) as u8;
    s[2] = (v[0] >> 16) as u8;
    s[3] = ((v[0] >> 24) | (v[1] << 2)) as u8;
    s[4] = (v[1] >> 6) as u8;
    s[5] = (v[1] >> 14) as u8;
    s[6] = ((v[1] >> 22) | (v[2] << 3)) as u8;
    s[7] = (v[2] >> 5) as u8;
    s[8] = (v[2] >> 13) as u8;
    s[9] = ((v[2] >> 21) | (v[3] << 5)) as u8;
    s[10] = (v[3] >> 3) as u8;
    s[11] = (v[3] >> 11) as u8;
    s[12] = ((v[3] >> 19) | (v[4] << 6)) as u8;
    s[13] = (v[4] >> 2) as u8;
    s[14] = (v[4] >> 10) as u8;
    s[15] = (v[4] >> 18) as u8;
    s[16] = (v[5]) as u8;
    s[17] = (v[5] >> 8) as u8;
    s[18] = (v[5] >> 16) as u8;
    s[19] = ((v[5] >> 24) | (v[6] << 1)) as u8;
    s[20] = (v[6] >> 7) as u8;
    s[21] = (v[6] >> 15) as u8;
    s[22] = ((v[6] >> 23) | (v[7] << 3)) as u8;
    s[23] = (v[7] >> 5) as u8;
    s[24] = (v[7] >> 13) as u8;
    s[25] = ((v[7] >> 21) | (v[8] << 4)) as u8;
    s[26] = (v[8] >> 4) as u8;
    s[27] = (v[8] >> 12) as u8;
    s[28] = ((v[8] >> 20) | (v[9] << 6)) as u8;
    s[29] = (v[9] >> 2) as u8;
    s[30] = (v[9] >> 10) as u8;
    s[31] = (v[9] >> 18) as u8;
    s
}
```

`as u8` 是截断转换：只留低 8 位，正好实现「取这段 bit」。`fe.rs` 完成。下一节写梯子本体 `x25519.rs`。
