# 2.1 ssh 登录 GPU 主机

这节解决「怎么连上那台 GPU 主机」。已经能 ssh 上去的读者可以跳过。

## 基本登录

在自己的电脑上打开终端：

```console
$ ssh user@gpu-host
user@gpu-host's password:
```

`user` 是主机上的用户名，`gpu-host` 是主机的 IP 或域名。连上之后，你敲的所有命令都在那台机器上执行——本书后面所有命令都默认在这个 ssh 会话里跑。

💡 **补给：第一次连接的 fingerprint 提示。** 首次连接会问 `Are you sure you want to continue connecting (yes/no)?`，这是 ssh 在让你确认对方机器的「指纹」，输 `yes` 即可，之后不会再问。

## 免密登录（可选但推荐）

每次输密码很烦。在自己电脑上：

```console
$ ssh-copy-id user@gpu-host
```

这把你本机的公钥追加到主机的 `~/.ssh/authorized_keys`，之后 `ssh user@gpu-host` 直接进。如果本机还没有密钥对，先 `ssh-keygen` 一路回车生成一对。

## 防断线：tmux

搜 5~6 字符的前缀要跑几分钟到几小时，ssh 一断程序就没了。登录后先开一个 tmux 会话：

```console
$ tmux new -s vanity
```

断线重连后用 `tmux attach -t vanity` 回到原会话，程序还在跑。Arch 上安装：`sudo pacman -S tmux`。

## 确认显卡在位

```console
$ lspci | grep -i vga
03:00.0 VGA compatible controller: Advanced Micro Devices, Inc. [AMD/ATI] Navi 31 [Radeon RX 7900 XT/7900 XTX]
```

能看到 AMD 显卡型号，就可以进入下一节装 Rust 了。
