# 3.6 费马小定理求逆与加法链

这节讲梯子的收尾：怎么在有限域里算 z 的逆元 z⁻¹。不除法，用幂。

## 费马小定理

模素数 p 的有限域里，对任何非零 z 有 z^(p−1) ≡ 1。两边各除一个 z：

```text
z⁻¹ = z^(p−2) = z^(2^255 − 21)
```

求逆 = 算一个 255 bit 指数的大幂。问题是：怎么算得快。

## 朴素做法太贵

`z^(2^255−21)` 如果老老实实逐位平方-乘，需要约 255 次平方 + 约 128 次乘法。乘法比平方贵（更多 limb 交叉项），能省则省。

## 加法链：复用中间结果

观察指数的二进制：2^255−21 是一长串 1 加个小尾巴。利用 `z^(2^a − 1)` 可以快速升级为 `z^(2^(a+b) − 1)`：

```text
已知 x = z^(2^a − 1)，把 x 平方 b 次得 z^((2^a−1)·2^b)，
再乘上 z^(2^b − 1)，就得到 z^(2^(a+b) − 1)。
```

于是像滚雪球一样：z^9、z^11 这两个小幂是链的种子，由它们滚出 z^(2^5−1) → z^(2^10−1) → z^(2^20−1) → z^(2^40−1) → z^(2^50−1) → z^(2^100−1) → z^(2^200−1) → z^(2^250−1)，最后补 5 次平方乘上早年存的 z^11，正好到 z^(2^255−21)。

这是 ref10 留下的固定**加法链**，总共 **254 次平方 + 11 次乘法**，比朴素做法省下一百多次乘法。

## 代码长什么样

第 4 章 `invert` 就是这条链的直译，形状全是这样：

```rust
let mut t2 = sq(&t1);
for _ in 1..50 {
    t2 = sq(&t2);
}
let t2 = mul(&t2, &t1); // z^(2^100 - 1)
```

「平方 1 次 + 循环里再平方 49 次」合起来 50 次。每段的注释标出了当前指数，方便和加法链对照。你看懂这段，整个 `invert` 就没有任何神秘之处了。

## 为什么值得单独一节

求逆在每个密钥上只跑一次，但它是 X25519 里最容易写错、也最难从教科书直接抄的部分（教科书写「用扩展欧几里得」，在延迟归约的 limb 表示下并不顺手）。加法链方案只有平方和乘法——恰好是我们已经验证过的两个原语，测试风险最小。
