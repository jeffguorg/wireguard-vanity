# 3.4 进位与模 2^255-19

这节讲 carry 的规则和那个神奇的 19。看完你就完全理解第 4 章 `carry` 函数的每一行。

## 进位：满 26 进一

10 个 limb 合起来表示一个大数，每个 limb 有自己的「位宽预算」（26 或 25 bit）。某个 limb 超预算时，把超出的部分割下来、加给下一个 limb：

```text
c = v[i] >> 26;   // 超出 26 bit 的部分
v[i+1] += c;      // 进给下一个
v[i]  &= M26;     // 自己只留低 26 bit（M26 = 2^26 - 1）
```

奇数 limb 换成 25 / M25。这和小学竖式「满十进一」一模一样，只是进制是 2^26 / 2^25。

## 19 从哪来

模数 p = 2^255 − 19，移项得：

```text
2^255 ≡ 19  (mod p)
```

也就是说：**第 255 位的「1」可以换成最低位的「19」**。最高 limb v[9] 的权重是 2^230，占 25 bit，到 2^255 为止。v[9] 超出的部分 c 代表 c·2^255，模 p 意义下等于 c·19，加回 v[0]：

```text
c = v[9] >> 25;  v[0] += 19 * c;  v[9] &= M25;
```

这就是「模 2^255−19」在我们表示法里的全部体现——没有除法，没有取余，只是一次乘 19 的折回。选 2^255−19 这种「距离 2 的幂很近」的素数（伪梅森素数）正是为了这个便宜。

折回后 v[0] 可能又超 26 bit，所以 carry 最后再补一段 `v[0] → v[1]` 的进位收尾。

## 乘法里的 19 和 38

乘法（4.4 节）中 v[i]·v[j] 的权重是 2^(w(i)+w(j))。指数超过 255 的项同样按 2^255 ≡ 19 折回，系数带一个 19。还有个小细节：奇 limb × 奇 limb 的权重比落点多一个因子 2——比如 limb1×limb1 的权重是 2^(26+26) = 2^52，而落点 limb2 的权重只有 2^51——所以该项系数要 ×2；折叠项在 19 之上再乘这个 2，就是 19×2 = **38**。代码里 `f1_2`、`g1_19` 这些变量名就是这么来的——4.4 节见到时不用慌。

## 强归约：打包前的最后一次

carry 只保证 limb 在位宽内，数值上仍可能 ≥ p（比如等于 p+5）。打包成字节前必须做**强归约**：判断值是否 ≥ p，是就减 p。技巧（4.7 节 `to_bytes`）：给 v[0] 加 19q 再进位，若原值 ≥ p 则最高位会自然溢出丢掉，效果等于减 p——全程无分支，GPU 友好。
