# 4.3 fe.rs：carry 进位

这节写 `carry`——弱归约，把超位的 limb 压回位宽内。它是后面 mul/sq 的收尾步骤，也是 3.4 节理论的直译。

## 代码

把下面函数插入到 `fe.rs` 中 `impl Fe { ... }` 之后、`add` 之前：

```rust
/// 弱归约：依次把每个 limb 超出的部分进位到下一个 limb，
/// limb9 的进位乘以 19 回到 limb0（因为 2^255 ≡ 19 mod p）。
pub fn carry(h: &Fe) -> Fe {
    let mut v = h.0;
    let mut c: u64;
    c = v[0] >> 26; v[1] += c; v[0] &= M26;
    c = v[1] >> 25; v[2] += c; v[1] &= M25;
    c = v[2] >> 26; v[3] += c; v[2] &= M26;
    c = v[3] >> 25; v[4] += c; v[3] &= M25;
    c = v[4] >> 26; v[5] += c; v[4] &= M26;
    c = v[5] >> 25; v[6] += c; v[5] &= M25;
    c = v[6] >> 26; v[7] += c; v[6] &= M26;
    c = v[7] >> 25; v[8] += c; v[7] &= M25;
    c = v[8] >> 26; v[9] += c; v[8] &= M26;
    c = v[9] >> 25; v[0] += 19 * c; v[9] &= M25;
    c = v[0] >> 26; v[1] += c; v[0] &= M26;
    Fe(v)
}
```

## 逐行对照 3.4 节

- 前 9 行是普通的「满 26/25 进一」链，从 limb0 一路推到 limb9；
- 第 10 行是模数折回：limb9 溢出的 c 代表 c·2^255 ≡ 19c，乘 19 加回 limb0；
- 最后一行是折回的收尾：limb0 刚被加了 19c 可能又超 26 bit，再往 limb1 推一次。

为什么 11 行就够了：进位链每推一格，c 都至少缩小 2^25 倍，折回加上的 19c 很小，最后一次 limb0→limb1 进位后不可能再引发连锁反应。

## 为什么叫「弱」归约

carry 后每个 limb 都在位宽内，但整个数仍可能 ≥ p（例如恰好等于 p）。对继续运算（mul/sq 的输入要求 limb 足够小）来说这没问题；只有最终打包成字节时才需要把 ≥ p 的情况消掉（强归约，4.7 节）。

## 一个实现细节

`carry` 接收 `&Fe`、返回新的 `Fe`，不动入参——本书所有域运算都是这个风格（纯函数）。这在 Rust 里几乎零成本（`Fe` 是 `Copy` 的 80 字节结构，编译器会内联优化），到 GLSL 里更好办：结构体本来就是按值传递的。
